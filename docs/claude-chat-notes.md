## 1. 语言路线 ✅（2026-10-25 已被第 0 节取代）

纠结了两天“中文还是英文”，最后定了：**走孙宇晨式路线**。

| 阶段 | 时间 | 做什么 |
|---|---|---|
| 一 | 现在 → 2027 夏 | 在中文圈建立影响力：**中文 YouTube（100% 露脸）+ 中文 X**。同时每天练英文。 |
| 二 | 2027 起 | 用影响力去做事：找合伙人、做项目、创业。中文观众和人脉 = 第一批用户和支持者。 |
| 三 | 之后 | 靠公司和产品走向全球。英文练成后再开英文频道，或直接以创始人身份在英文世界发声。 |

**为什么这么定**
- 中文是现在的“战场”，英文是“训练兵团”（进击的巨人：先在训练兵团练好，再上战场）。
- 之前做过英文 YouTube，说话磕磕巴巴，效果差。现在硬上英文 = 两头都慢。
- 日漫的例子：内容是日语，照样卖向全世界。好内容 + 渠道，比语言本身更重要。
- 孙宇晨走向全球靠的不是把自媒体换成英文，而是做出了公司。**自媒体是起点和杠杆，创业才是主线。**
- 注意：孙宇晨争议很大（被 SEC 起诉过，营销手法常被批评）。学他的路径和执行力，不学全部。

**英文的位置**
- 从 **10/29** 开始，每周发 1 条**英文 YouTube Short**，当练习，不追数据。
- 约 **2027-01-23** 复盘一次，看要不要调整（包括要不要开英文 X）。

## 2. 英语口语训练计划 ✅

**目标：2027-06-01 能对着镜头不看稿说 3 分钟英文。**

**每天**
- 午饭后跟读（shadowing）15 分钟。
- 下午走路回去时，对着手机用英文说 2 分钟（讲今天干了什么）。只录不发。
- 写 10 分钟英文，发给 Claude 改。

**每周**
- 回听一条录音，找出并改掉一个问题。
- 在社团里用英文说 5 分钟话。
- 发 1 条英文 Short（10/29 起）。

**里程碑**

| 时间 | 标准 |
|---|---|
| 10–11 月 | 看着笔记说 1 分钟 |
| 12–2 月 | 只看 3 个关键词说 2 分钟 |
| 3–5 月 | 不看任何东西说 3 分钟 |
| 2027-06-01 | 正式测试 |

每月录一条 3 分钟测试视频存着，以后可以剪成一期“英语进步”视频。

## 3. 每日系统 ✅（2026-10-14 定）

**核心方法：输出倒逼输入。** 先定今天发什么，再为它去学。

**每天固定**
| 输入 | 输出 |
|---|---|
| 读书 | X：1 条推（一个观点 + 我的看法） |
| LeetCode | GitHub（偶尔发推） |
| X 互动（约 40 分钟） | 回复大号、发推 |
| **每天学懂一个新东西**（火箭原理、凯利公式、某道题、美股复盘……） | **YouTube：1 期** |
| 英语 | 走路时用英文把今天学的东西讲 2 分钟，只录不发 |

**一句话定位**
> 一个 19 岁的人，每天学懂一样东西讲给你听。

- 题目可以很散，靠"我"这条线串起来：观众看的是我学的过程。
- 不另开 LeetCode 频道，所有内容都放进同一个频道。

**日更保底规则**（防止断更）
- 最低标准：手机录、3–5 分钟、不剪或少剪。**发出去比做精致重要。**
- 当天剪不完，第二天发也算完成；但不能连续两天不发。
- 作业每天 1.5 小时照常做，成绩是底线。
- 每周日花 15 分钟回看数据，挑反响最好的题以后做长版。

**选题池**（来源：读书、课、美股、播客、刷题、好奇心）

| # | 题目 |
|---|---|
| 1 | 胜率 60%，每次梭哈，第几把破产？（凯利公式） |
| 2 | 真金白银炒美股 4 个月，我学到了什么 |
| 3 | 跟单博主 vs 直接买 QQQ，谁赚得多？（用 yfinance 数据） |
| 4 | UCSD 数学 + 经济专业的一天（带出在读的书、在听的播客） |

## 4. 第 1 期 🔄 2026-10-13 改题

**新题 ✅：《年轻人为什么做自媒体》**（价值观板块，6–8 分钟）。Alx 不想讲凯利公式。
- 角度：19 岁、9 个订阅、站在起点讲"我为什么开始"（同题材的人都是成功后回头讲）。
- 提词稿：`docs/scripts/ep01-why-i-started.md`；调研：`docs/references/why-young-people-self-media.md`、`docs/references/youtube-playbook.md`。

**以下凯利公式大纲作废，留作以后的美股选题。** 注意：钩子"大概第 5 把破产"不准确，每把全押时平均第 2–3 把破产，活过 5 把的概率约 8%。

1. **钩子（30 秒）**：“假设你有 60% 的胜率，每次都 All in，第几把会破产？答案是：大概第 5 把。”（Claude 之前跑过模拟）
2. **我是谁（30 秒）**：19 岁，UCSD 数学和经济，在美国炒美股，目标是做一家自己的公司。
3. **为什么做这个频道（1 分钟）**：记录一个普通大学生怎么从零开始搞钱、学东西、创业。全部真实，不装。
4. **揭晓答案（1–2 分钟）**：凯利公式讲人话版。胜率高也不能梭哈，活下来比赚得快更重要。
5. **结尾（15 秒）**：“我是 Alex，明天见。”
6. 加一行字幕：**不构成投资建议**。

第一次录不用正式，可以在去星巴克的路上随便聊着录。

## 5. 规矩 ✅

- 视频里**不报具体持仓、不给买卖建议**，加“不构成投资建议”。
- 发布到 YouTube / 抖音一律**手动**，不让 AI 自动上传或登录平台。
- API Key 不贴进聊天；必须用的话，用单独的 Key、设消费上限，用完撤销。
- 不在镜头上说“我要超越马斯克”（Alx 自己觉得太“嘉豪”）。目标放心里，用行动证明。
