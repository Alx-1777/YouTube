ID: LWvykGhjN18 · 7:53 · 603 播放 · https://www.youtube.com/watch?v=LWvykGhjN18

**要点**
- 多数口播把观众当"表达对象"：正对镜头、指指点点地"教你"，让人想起课堂和老师，观众本能地有压力。
- 自媒体的底色是放松娱乐，就算讲干货也要"寓教于乐"，把药裹上糖衣，别把课堂搬上来。
- 更好的位置是让观众当**旁观者 / 围观者**：可以随时走、保持匿名、居高临下地看，所以安全、有耐心、有好奇心。
- 做法：对着身边一个人（助理、朋友）讲，而不是盯着镜头讲；双人聊天、一问一答，节奏快、信息密，最好看。
- 采访类不要长片头、念采访提纲，直接切进问题，让观众像看纪录片一样"偷看"。

**对我们的启发**
- How It Works 的视角天然适合"围观"：主角是 3D 模型，Alx 是"带你一起拆开它"的人，而不是讲台上的老师。脚本里少用 "You need to know…" "Let me teach you…"，多用 "Let's open it up and see…" "Look at this…"，把观众放在 Alx 身边一起看。
- 可以试一种形式：Alx 一边转 3D 模型一边自言自语式地发现（"Wait, why is this part so big?"），观众是在看他好奇，而不是被上课。这也贴合 README 的"核心是好奇心"。
- 和 youtube-playbook 里老胡"不准备马上开始"不冲突，是补充：口播技巧上要避免"传达文件精神"的语气，录制时可以想象对一个朋友讲解。

## 2026-11-02｜【油管为什么】为什么 MrBeast 先做封面再拍视频？
ID: m8OirwdjSDM · 12:09 · 2177 播放 · https://www.youtube.com/watch?v=m8OirwdjSDM

**要点**
- 他看到一个近两万人的投票：约 86% 的人先拍视频，上传时才临时做封面、写标题。
- 没有绝对唯一的正确顺序（有人先做封面，有人先打粗稿边拍边改），但封面和标题的构思**绝不能放到最后**。
- 封面图可以当选题过滤器：看封面草图没有"忍不住点进去"的冲动（生理反应或好奇），这个题就不该拍。
- 选定题目后，搜别人同题的图片/封面，看灯光、背景、角度、道具，提前想好自己的画面；拍完才想封面，很多镜头已经没法补拍了。
- **标题比封面更重要**：标题是这期内容的边界，先定标题，讲故事才不会跑题、乱。
- 两个常见错误：①加入无关细节（舍不得剪自己喜欢的镜头）；②关键信息缺失（假设观众看过前因后果）。好记者会把背景简短交代清楚。
- 团队可以开会讨论封面和标题，有的团队一期写到 20 个标题反复筛；MrBeast 每期先做多个封面。

**对我们的启发**
- 落到流程上：Claude 写英文脚本**之前**先出 3–5 个英文标题 + 1–2 个封面草图（3D 模型的哪个画面 + 1–3 个词），Alx 选定后再写脚本。可以加进 README 分工流程第 1 步"选题"。
- 封面草图直接决定 3D 模型要做什么：比如火箭那期，封面想要"火箭剖开、90% 都是燃料罐"的画面，就要确保模型里有这个剖面视角和录屏角度。
- "关键信息缺失"对日更系列也有用：每期都要假设观众是第一次来，不要说 "as I said yesterday"，需要的背景一句话交代。这和 playbook 里 MrBeast "先做封面" 的记录一致，这里补充了"标题定边界"这一层。

## 2026-10-30｜【油管基础课】 什么是完播率？多大的完播率才算好？为啥有时完播率高播放量反而不高？
ID: UD7W1HGPgq0 · 3:32 · 418 播放 · https://www.youtube.com/watch?v=UD7W1HGPgq0

**要点**
- 完播率（观看完成度）是视频质量的核心指标，也是推荐的重要因素。
- 没有"多少算好"的绝对数字：1 小时访谈的 30% 可能比 30 秒搞笑视频的 80% 更好。
- 平台的做法是先按**内容类别、时长**等把可比的视频分组，再在组内按完播率排序推荐。
- 所以你频道里"最高的 60%"，放到同类同长度视频里可能仍然偏低，照样拿不到推荐。
- 我们看不到别人的完播率，纠结"55% 好不好"没有意义。
- 唯一能做的是跟自己比：这期 55%，下期争取 58%、60%……先做"村里最好"，再一级一级往上比。

**对我们的启发**
- How It Works 是 8–12 分钟科普，对手是 Kurzgesagt、Veritasium、Branch Education 这一档，完播率要和**同类同长度**比，不要拿 Shorts 的数据安慰自己。
- 每期复盘记一个数：平均观看百分比，和上一期比是涨是跌，再去看留存曲线在哪一段掉得最多（通常是钩子之后、讲原理那段）。周日复盘时把它加进固定检查项。
- 和 youtube-playbook.md 里 Ali 的"YouTube 只在乎点击、观看时长、满意度"一致，这里补充了"组内比较"的机制。
